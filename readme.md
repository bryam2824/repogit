Después de trabajar desde la terminal con el Subsistema de Windows para Linux (WSL) y Git, se continúa el desarrollo en Visual Studio Code (VS Code). Es importante gestionar correctamente las claves SSH y la conexión con GitHub, ya que una configuración inadecuada puede generar problemas de sincronización entre el entorno local y la nube.

Sin duda, es un proceso de aprendizaje constante. Actualmente, GitHub permite realizar modificaciones que posteriormente pueden enviarse y sincronizarse con el entorno local, facilitando así la colaboración y el control de versiones del proyecto.
